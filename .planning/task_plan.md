# 3D 跑酷游戏原型 - 任务计划

## 需求概要
在现有游戏平台中新增一个 3D 第三人称跑酷游戏，使用 Three.js 渲染。

## Phase 1: 基础设施 [in_progress]
- [ ] 安装 Three.js 依赖
- [ ] 在 index.html 添加游戏菜单项
- [ ] 在 main.js 注册游戏（gameInfo、startGame switch、stopCurrentGame 清理）

## Phase 2: 3D 场景核心 [pending]
- [ ] 创建 Three.js 场景、相机（第三人称追尾）、渲染器
- [ ] 三条平行跑道（左/中/右）
- [ ] 玩家角色（简单几何体组合）
- [ ] 跑道无限生成 + 身后销毁

## Phase 3: 玩家控制 [pending]
- [ ] 虚拟摇杆：左右切换跑道、上滑跳跃
- [ ] 滑行按钮：俯身滑行 1 秒
- [ ] 键盘备用控制（A/D 切换、W 跳跃、S 滑行）

## Phase 4: 障碍与碰撞 [pending]
- [ ] 随机生成障碍物（高架杆、矮栅栏、地铁车厢）
- [ ] AABB 碰撞检测
- [ ] 矮栅栏 → 需跳跃、高架杆 → 需滑行
- [ ] 碰撞 → Game Over + 重启按钮

## Phase 5: 分数系统与体验优化 [pending]
- [ ] 顶部显示运行距离
- [ ] 金币生成 + 旋转 + 收集计数
- [ ] 速度随距离递增
- [ ] 视觉风格：深灰跑道、红色障碍、金色金币
